# FiskAI

**Organizirajte poslovne dokumente i katalog na jednom mjestu.**

FiskAI je hrvatska Android aplikacija za pripremu računa i ponuda, upravljanje kupcima, dobavljačima i artiklima te lokalnu evidenciju poslovanja.

| | |
|---|---|
| 🧾 **Računi i ponude** | Sastavite nacrte, izračunajte iznose i izvezite PDF. |
| 👥 **Kupci i dobavljači** | Organizirajte kontakte i provjerite format OIB-a. |
| 📦 **Proizvodi i usluge** | Šifre artikala, KPD oznake i povijest maloprodajnih cijena. |
| 🔒 **Privatnost** | Lokalno šifrirani poslovni zapisi. |
| 📦 **Skladište i POS** | Evidencija kretanja zaliha i POS košarica za nacrte računa. |
| 🏢 **Poslovne postavke** | Poslovni subjekt, prostori, uređaji i operateri. |

## FiskAI Web

Javni pregled aktualnih i arhivskih cjenika, CSV i XML datoteke te pretraživanje službenog KPD kataloga nakon uvoza podataka. [Web dokumentacija](web/README.md).

KPD oznake možete pretražiti i odabrati iz povezanog HTTPS kataloga. Izvoz testnih UBL nacrta omogućuje provjeru strukture dokumenata prije dovršetka eRačun integracije.

[Snimke stvarne aplikacije i testovi na uređaju](https://github.com/bren-wp/FiskAI/actions/workflows/device.yml) — CI artefakti nakon uspješnog izvođenja na emulatoru.

## Preuzimanja

[GitHub Releases](https://github.com/bren-wp/FiskAI/releases) — planirani paketi v0.1.0: instalacijski APK (potpis za testiranje), zasebni DEMO APK i nepotpisani release AAB za kasnije potpisivanje. Izvorni kod obuhvaća Android, web, server i brending.

## Dostupnost

Trenutačna verzija namijenjena je testiranju. Dokumenti su nacrti, a fiskalni moduli nisu odobreni za produkcijsko izdavanje računa. Bazne cijene i KPD zahtijevaju provjeru izvora. Slike iznad su vektorski identitet, ne snimke aplikacije.

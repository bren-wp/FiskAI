# Stvarne snimke FiskAI

CI Android device and screenshots pokreće instalirani APK na emulatoru API 36, izvršava instrumentacijske testove i snima stvarne zaslone. Artefakt FiskAI-real-screenshots-api36 sadrži PNG datoteke nakon uspješnog izvođenja. Snimke nisu ručno simulirani dizajni. Originalne reference iz branding/ ostaju odvojene. PNG datoteke se ne objavljuju kao marketinške snimke dok se ne pregledaju i ne usporede s odobrenim dizajnom. Pixel-perfect verifikacija još nije završena.

# Platni kodovi

HUB-3A EUR: https://www.hub.hr/hr/format-zapisa-pdf417-2d-bar-koda-prema-hub3-standardu — 14 polja, UTF-8, binarna kompakcija, 9 podatkovnih stupaca, korekcija 4, omjer modula 3:1. Implementiran ograničen model HR99 bez poziva na broj. Polja se ne skraćuju neprimjetno. EPC069-12 v3.1: https://www.europeanpaymentscouncil.eu/document-library/guidance-documents/quick-response-code-guidelines-enable-data-capture-initiation — SCT 002, UTF-8, razina M, ograničenje 331 bajta i verzije 13. Hrvatski IBAN i EUR. Koristi se ZXing core 3.5.4 (Apache-2.0). Iznos, račun i primatelj prikazuju se uz kod. Nema izvršavanja plaćanja, nema koda za naplatu nacrta kao izdanog računa. Potrebna verifikacija s bankovnim aplikacijama, fizičkim ispisom HUB-3A i ECI kompatibilnošću. Unit testovi generiranja i dekodiranja dodani, rezultat još nije potvrđen.

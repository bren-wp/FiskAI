# FiskAI Web

Javna web stranica nalazi se u `public/`. Na hostingu postavite `web/public` kao jedini javni document root. Direktorij `server/` mora ostati izvan javnog korijena i biti dostupan PHP procesu kao susjedni direktorij. Upute za SQL, konfiguraciju, KPD i API: [server/README.md](../server/README.md).
